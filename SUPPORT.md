# Support

ANNEX is an open-source project maintained by volunteers. This page explains
where to get help.

## Documentation first

- Read the [README](README.md) for setup, architecture, and the tech stack.
- Read [CONTRIBUTING.md](CONTRIBUTING.md) if you plan to contribute.

## Getting help

| Need                | Where to go                                   |
| ------------------- | --------------------------------------------- |
| Bug reports         | Open a [GitHub issue] with repro steps        |
| Feature requests    | Open a [GitHub issue] labeled as a proposal   |
| How-to questions    | Open a [GitHub discussion] or an issue        |
| Security issues     | See [SECURITY.md](SECURITY.md) — **not** an issue |

## What to include in a bug report

- What you were trying to do.
- The exact steps to reproduce.
- Expected vs. actual behavior.
- Environment: OS, Python version, Docker/Cloud Run context if relevant.
- Any error output or logs.

## What we do not support

- Guaranteed response times (volunteer project).
- Help with other projects that use ANNEX's dependencies (Supabase, OpenAI,
  FastAPI) — check those projects' own support channels.
- Production-specific assistance beyond what is documented.
